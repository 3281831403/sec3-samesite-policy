会话 Cookie 没设同站属性，第三方页面里的表单提交时浏览器照样把它带上，跨站请求就成功了：会话类 Cookie 必须显式设置同站策略，跨站可用的 Cookie 必须同时带有安全传输标记；属性名大小写不敏感；非法取值必须按最严格处理；同一属性重复出现时取最严格而不是最后一个；批量校验时各 Cookie 相互独立。无论输入怎样，会话 Cookie 一定带有同站限制，任何取值都落到严格、宽松、无三个合法值之一。
